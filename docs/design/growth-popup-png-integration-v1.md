## 2026-11-10：来自真实 iPhone 截图的重大问题与修正

用户的三张实拍截图证明：
- 月历上的 `PNG 已启用 · 5/5` 意味着五张图已加载成功，**不能再把布局混乱归咎于缺图**。
- 打开日期详情后背景框架过高，部分内容与花草、标题错位。
- 向下滚动时纸面/外框消失，动态文本与卡片单独浮在模糊页面上。
- 复用的绿边纸框显示出白色直角矩形，立体质感与目标图不符。

因此已修正 `dist/growth-popup-png.css`：
1. 日期详情 modal `[open]` 采用固定视口高度，避免弹窗本身跟着长内容移出屏幕。
2. 内部 surface 改成 flex-column 且占满弹窗可用高度；只允许 `.up-dialog-body` 进行内部滚动。
3. surface 以实体奶油色作为不透明兜底，即使 iOS Safari 的九宫格伪元素渲染出现问题也不能透明。
4. 清除带直角外底的内容框 CSS 背景，改用项目原有暖金色高分辨率纸框 `today-homework-frame-v1.webp`。
5. 约束实际图片渲染的九宫格与四个正文模块，不修改任务、课程、心情的数据。

补充的移动端回归测试会检测 **滚动前后弹窗外框坐标不变、背景不透明、内部正文可滚动、无直角白色方框**。CSS 结构检查通过。
