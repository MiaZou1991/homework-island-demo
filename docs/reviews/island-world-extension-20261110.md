## 目标与已确认的约束
- 用户否定顶部“相近蓝色拼接条”、纯色遮盖与简单整图上移，明确同意 **主场景原图 + 独立延展场景背景**。

- 保留一张原始主图：`dist/assets/hd/today-island-reference-v1.webp`（900×1748），按宽度同比例渲染，不拉伸变形。

## 图层与素材
1. **全屏延展背景**：`dist/assets/hd/island-world-extension-v1.svg`。手工绘制的矢量天空、柔云、远处绿岛、海平线及波光。适合 iPad 横竖屏和较高页面，独立于 UI、滚动不可操作，按全屏自适应扩展。属于新辅助素材，最终画风仍需用户确认。
2. **中央小岛主图**：`.tf-world-main`，仍引用批准的 `today-island-reference-v1.webp`。保留图片完整比例；iPhone 沿用上移约 34–44 CSS px 的已验方案；在 iPad 只羽化左右边缘以融入大背景，不给正文 UI 加透明遮罩。
3. **UI DOM 层**：Logo、积分、今日作业、课程提醒、心情与伙伴按钮，保持独立可交互并且不随图片做拉伸。
4. **导航层**：原三枚 Tab 固定底部；沿用 P0 安全区适配，与背景扩展无耦合。

## 设备策略
- iPhone 320、375、390、430 CSS px：原图占据主体宽度；独立延展层补足原图以外的区域，顶部无另造纯色拼接条；Logo 独立遵循安全区。
- 531–699 CSS px：仍使用原手机大小的卡片排版，主图两侧轻量羽化。
- iPad 768、1024、1366 CSS px：中心交互栏最大 500px；两侧由矢量延展场景补齐；卡片文字/图标不随整张背景拉伸；保留背景独立图层。
- 需在 Safari 普通标签页及「添加到主屏幕」两种运行方式分别验收。Safari **原生浏览器的系统状态栏/地址栏不属于页面画布**；浏览器可能根据主题色绘制系统区，网页无法强制把插画绘到浏览器保留区域。PWA 可在支持的条件下让网页延伸到安全区，但依然受 iOS 控制。
- 对于短高度横屏，遵循 P0 的安全区和固定 Tab；内容允许纵向滚动，不强制缩小作业。

## P0 验收点
1. iPhone 首页原图与延展层没有额外纯色矩形或水平硬断层；主图清晰、位置稳定。
2. iPad 竖屏/横屏：场景扩展到左右，灯塔和建筑比例不变、居中；不存在横向溢出。
3. 主景与作业卡、角色站位自然，Logo/积分和手势条安全，底部 Tab 位置不漂移。
4. 弹窗图鉴保持三列、列表独立滚动、选中态单层描边；新增的小老鼠（17 个伙伴）不回退。
5. 不修改家庭数据、积分、物品和课程业务行为。
