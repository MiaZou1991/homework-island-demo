# 作业岛儿童端弹窗视觉规范 V2（2026-10-28）

参考用户确认的三联视觉稿：记心情、陪伴伙伴、我的完成时刻。稿件是视觉方向；实际内容与业务状态由现有数据决定，不把整张稿当页面图片。

## 共用外壳

- 奶白色、微不规则手绘面板，淡绿色细边和柔和阴影。面板继续使用独立的 `dialog-panel-v1.svg`，内容保持 DOM。
- 木质花叶标题牌横跨面板上缘。采用 `dialog-title-v1.png` 作透明素材，标题为实时文字，在木牌可见木纹区内水平和垂直居中；字色深棕 `#613817`，寒蝉圆黑体，手机字号约 20–25 CSS px，长标题不压住花叶。
- 背景遮罩为半透明蓝绿并轻微模糊，保持海岛气氛。
- 关闭按钮在面板**下方正中**，距面板底边 12 CSS px；奶白圆形、棕色 ×、44×44 CSS px 点击区。面板和标题保持静止，长正文独立滚动。
- 主按钮为有轻微手绘不规则感的绿色圆角矩形，约 49px 高，浅绿高光、深绿底边；不要长椭圆或额外星星。

## 内容模板

- 记心情：标题后为提问；3×2 奶油小卡片，六个独立 `dist/assets/hd/moods/*.svg` 表情、名称。选中使用细绿色描边与浅奶油底，不加大勾。下方独立标签、白色输入框、字数与可选提示、绿色保存按钮、历史入口。
- 陪伴伙伴：绿色选中分段按钮；3×2 伙伴卡片，选中描绿边。当前伙伴区使用淡奶油卡片，角色与文字并排。实际可选择/解锁伙伴与积分来自现有数据，不能用视觉稿虚构的六位伙伴替换数据。
- 我的完成时刻：角色居中、脚下自然接触阴影、少量星光；随机坚持类短句；原作业标题；淡黄色两行奖励记录。积分和建设力沿用既有计算，不额外加分。
- 其他儿童端弹窗也使用此共用外壳、标题牌、按钮和关闭规则；内容可随功能变化。

## Logo 与 Tab

- 两页左上角继续用生产素材 `wordmark-wood-hd.webp` 与绿色屋顶小屋；文字和小屋门为深棕色。底部继续用 `tabs-clean.webp` 的原三枚立体图标，顺序：今日任务、小岛日程、我的小岛。小屋门保持棕色；选中仅在文字下使用奶白手绘底框。
- 保持素材颜色，不把小屋、字样或 Tab 重绘成另一种图标。

## 验收

390px 及常见小屏下检查三种示例弹窗与其他旧弹窗：标题不压花叶；正文不碰关闭按钮；正文滚动时关闭按钮不动；心情保存、伙伴选择与完成奖励仍按既有逻辑。课程及携带物品只提醒、不打卡。

## 记心情细节修订

标题木牌与面板比例收窄，提问区上移；六个表情各用独立 72×72 SVG，径向渐变、局部高光、腮红和小阴影增强质感。在 DPR2/3 下使用矢量源，不进行位图放大。奶油卡片使用暖色细边与 2px 浅阴影；保存按钮调整为柔和绿，背景遮罩用半透明蓝绿，保持场景色彩。
