# 开心岛｜家庭树 V2.1 开发与安全验收清单

状态：Draft PR 开发预览，不可直接发布。业务依据：用户确认的《开心岛家庭树 PRD V2.1（2026-11-10）》与全弹窗视觉参考。
分支依赖漫步 PR #16，其他对话继续负责 P0 家庭 Auth/同步、CAS 等，本次不修改其数据库或代码。

## 已开发
- 两个主入口：家庭记录、送爱心。家庭记录统一了成长回忆/便签及回复，最近至多三条挂树枝吊牌，点击看详情。
- 每位成员每天最多成功送两颗心，全家合计最多六颗；私密心意和家庭记录点爱心共用额度，禁止自己给自己送心和对同条记录重复点心。
- 按操作编号幂等去重；失败不扣额、不计累计，确认收到也不扣额。体验版按 Asia/Shanghai 模拟家庭自然日，生产必须由服务端固定家庭时区和时间。
- 时间阶段：0、6、18、30、42、60个月分别对应初芽树、幼树、成长树、开花树、繁盛树、家庭大树，未满五周年不得提前解锁大树。
- 爱心装饰候选门槛：1、10、30、60、120、240、400、650、1000。每阶段装饰容量2、3、4、5、6、8；不送心不退级。
- 2月29日周年遇非闰年按2月28日，激活日应由服务端只写一次。

## 重要未完成事项，合并前阻断
1. **成员身份**：本分支成员下拉框只用于演示，并非身份鉴权；私密爱心正文当前只在隔离 localStorage 测试，不能进生产全家共享 JSON。
2. **服务端事务**：真实2颗/天、跨设备并发、重复请求、累计心意聚合须服务端同事务校验；公开累计数值不得暴露私信内容。
3. **高清场景**：六成长阶段各需「全岛融合图」「树下近景图」，12张母图均须与花坛石沿、树根、阴影和透视无缝统一。当前资源尚未完成，不能再单独叠加树木PNG冒充最终效果。
4. **照片**：必须私有对象存储和授权访问，当前可选文件仅验证、不能保存，页面明示这一限制。
5. **实机**：iPhone Safari、键盘、低网速、全尺寸视觉和跨设备 Auth/CAS 后端验收仍待执行。
