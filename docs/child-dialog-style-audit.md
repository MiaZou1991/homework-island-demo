# 儿童端弹窗规范 · 2026-10-28

本规范覆盖新旧儿童端弹窗，后续新增弹窗必须使用相同容器。关闭按钮采用面板下方居中方案，替代此前右上角 25px 方案。

## 外观与布局

- 面板使用 `dist/assets/hd/today-icons/dialog-panel-v1.svg`，木牌使用 `dialog-title-v1.png`。内容、标题及按钮保持真实 DOM。
- 木牌标题区域在原位置基础上上移 20 CSS px、右移 10 CSS px。标题在木牌内垂直居中，字号与首页“今日作业”实际字号一致。
- 关闭按钮是独立奶白色圆形 ×，棕色细边、轻微不规则轮廓。放在面板下方居中；按钮顶边距面板底边 12 CSS px；按钮和点击范围均为 44×44 CSS px。不得放回木牌花朵旁或占用正文。
- 关闭按钮不参与正文滚动。长内容只在正文区域滚动，木牌与关闭按钮始终可见；给标题、底部按钮及设备安全区预留空间。
- 绿色主按钮使用轻微不规则圆角长条，保持克制高光和轻微凸起，避免拉成长椭圆。
- 所有关闭按钮使用原生 button、明确的“关闭弹层”无障碍名称和键盘焦点样式。关闭动作沿用原入口行为，不提交表单。

## 统一入口

全部任务、作业详情、完成记录、记心情、陪伴伙伴、伙伴图鉴、课程与日程详情、添加/编辑日程、删除日程确认、建设完成、兑换确认；旧版伙伴选择、个人资料和动态编辑器；非预览的家庭码与家长验证面板。

新弹窗通过 `upgrade.js` 的 modal 创建。旧弹层通过 `child-dialogs.js` 使用同一手绘外壳。样式唯一来源为 `child-dialogs.css`，禁止为单个弹窗另设关闭按钮位置。

## 验收

检查短弹窗及长表单：标题不裁切，底部按钮间距 12px、尺寸44px；滚动正文时关闭按钮不移动；关闭不触发保存或兑换。父端数据与任务奖励规则保持既有逻辑。

实测：心情弹窗与添加日程弹层，关闭按钮均为44×44px，距面板12px；720px高视口保留底部12px余量。正文滚动后保存入口可见，关闭按钮位置不变。
