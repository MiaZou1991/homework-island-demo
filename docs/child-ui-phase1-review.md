# 儿童端阶段一预览与验收记录

依据：用户选定的《作业岛：萌趣学习小岛界面》、像素还原 V2 原型、四场景与 UI 素材包，以及《作业岛儿童端功能说明 V2.0》。仅在 feat/child-ui-hd-assets 开发，不合并 main，不发布现有 Pages。

## 本轮完成

- 今日任务首页改为独立海岛插画、透明浣熊、原生地点按钮、作业预览卡、固定心情与伙伴入口，以及课程与专属物品合并提示卡。
- 三个底部 Tab 固定为今日任务、小岛日程、我的小岛，导航图标为独立 SVG。
- 作业只发放设置的积分；保留既有建设力、掉落和防重复领取机制。历史已结算的流水和余额不追溯重算，撤销按原流水扣回，再次完成按当前配置积分结算。
- 课程与活动及其携带清单均为只读提醒，无打卡、备齐数或课程积分。既有历史打卡字段留在备份中，但不用于新界面的完成状态。
- 首页进度只统计作业。明确结束时间已过的课程退出首页重点；缺少结束时间时不假定已结束。历史日期保留安排。
- 周/月日程、作业详情、心情保存、伙伴选择及现有小岛入口继续使用同一份家庭数据。
- preview=1 使用独立示例存储并禁用云端和家庭码入口；家长/儿童预览之间保留该参数。

## 素材与清晰度

| 资源 | 原始尺寸 | 最大 CSS 尺寸 | DPR2/3 |
| --- | --- | --- | --- |
| 独立海岛 | 1448×1086 | 430×280，按 cover 实测 | 足够；见 mobile-results.json 的实测比率 |
| 透明浣熊 | 1254×1254 RGBA | 128×150，contain | 足够；保留 Alpha |
| 导航、Logo 文字、木牌、任务图标、按钮与勾选框 | DOM/CSS/SVG | 自适应 | 矢量/真实字形 |
| 六件收藏替换图 | 256×256 RGBA | 通常 34×34 | 小尺寸候选，仍需按具体场景复核边缘 |

新插画是按目标风格生成的独立资源，不是从设计总览裁切，不含业务文字。实际生成尺寸如上，未放大到声称的 2K。无损母版保存在 assets/hd/masters/，页面使用压缩 WebP。新插画的风格相似度仍须用户对照确认，不能等同于原稿逐像素一致。

原素材逐项像素盘点见 hd-source-inventory.csv；它记录尺寸，不代表质量通过。资源大小见 hd-assets-manifest.json。

## 未通过和后续范围

- 四个区域的独立高清场景和自由拖放、撤销、保存尚未重建；现有小屋仍采用原有位置摆放方式。原四场景包带 UI 且来源为拼图，不作为正式高清场景。
- 部分旧伙伴图片仍是低分辨率；伙伴弹层和旧小岛页面尚未完成目标稿高保真替换。
- 收藏图鉴、限定活动、成长徽章仍沿用现有功能，没有新增积分或掉落种类，也没有把静态示例当作已上线活动。
- 时间阈值 60/30 分钟在文档中是建议，本轮不写死。仅按明确出发时间或进行中安排把课程卡前置；页面操作时不定时调换卡片。
- 无推送、重复活动或多端冲突解决的新承诺；旧版新增/编辑表单继续保留，字段齐全性与儿童编辑权限的全面审核尚待后续。
- 本轮是 P0 首页和 V2 核心规则的可运行实现，不代表 P1–P3 或整套像素级验收全部完成。

- 移动端：375/390/430 CSS px，DPR2/3 六组浏览器截图、溢出检查和两张新插画密度测量。测试脚本与结果见 checks/hd/。
