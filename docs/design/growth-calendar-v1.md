# 开心岛｜成长日历周／月一体化设计与开发基线 V1.0
更新：2026-11-10。状态：开发分支候选稿，尚待用户验收；不得视为已上线。

## 1. 已确认的产品决定
- 儿童端第二个底部 Tab 由“小岛日程”正式更名为“成长日历”；“今日任务”“我们的岛”不变，原图标、Logo、底部样式沿用。
- 周视图以一周七天的横向轻课表为主，按上午／下午／晚上分区，可点日期查看详情；保留成员筛选及“一句话记事”入口。
- 月视图是成长手账：整月日历 + 当月小记录 + 21天习惯摘要。整体以已认可的奶油纸张、浅木色、少量小花与岛屿场景为准，不新增独立手账 Tab。
- 心情仅从“今日任务”现有心情记录同步；心情文字可选，鼓励写几个字，不应与完成作业的表现混为一谈。
- 课程和物品只提醒，不打卡；任务完成星星必须是当天确有作业且全部完成；不新增积分或历史奖励计算。

## 2. 月历四种标记
| 标记 | 触发条件 | 来源 |
|---|---|---|
| 心情表情 | 当天记录心情 | 今日任务的心情记录 |
| 星星 | 当天至少一项作业且全部完成 | 原作业数据 |
| 叶子 | 当天至少完成一个习惯 | 习惯挑战 |
| 小花 | 当天记录一件特别时刻 | 手动成长小记 |

- 单个日期最多两个主图标，按“心情、星星、叶子、小花”优先级排列；其他以 +N 标示。
- 同一天完成多个习惯，月历只出现一片叶子；点击日期在详情中查看全部习惯。
- 心情图标展示实际心情样式，不统一用爱心；未来日期不得提前生成成长成果。
- 无作业时不出现完成星星；已完成作业撤销后重新计算。

## 3. 日期详情
- 点击月历日期或周课表日期，打开已有弹窗组件的当天成长手账，保留三 Tab 的页面上下文。
- 显示心情与短句、作业完成情况、日程回顾、习惯打卡、特别时刻。
- 心情入口复用已有日记编辑器；不二次保存或维护第二份心情。
- 特别时刻允许孩子手动写简短内容；不要求照片或插画编辑器。

## 4. 21天习惯挑战
- 第一阶段支持创建挑战、每日勾选／撤销、累计进度、月历印章；挑战不因中断而清零。
- 同一天同一习惯只能记一次；一天多个习惯在月历聚合。
- 习惯挑战是阶段性鼓励，不保证“21天必然养成习惯”。
- 后续迭代再实现“将习惯关联现有今日任务，任务完成即自动同步打卡”、家长编辑挑战与完成纪念收藏；这几项**本次分支未实现**。

## 5. 开发范围与数据兼容
- 已开发候选：改名、周课表、月历、四类标记、日期详情、现有心情联动、独立习惯挑战、特别时刻文字、保留成员筛选与原一句话添加日程。
- 新习惯和特别时刻作为附加记录存入现有家庭数据，不修改现有任务或课程字段；日程展示只读，避免增加课程和物品打卡。
- 不覆盖原有 Logo、导航图标、弹窗基础素材及今日任务内容。
- 需要通过各类手机宽度、心情保存、周／月切换、家庭成员筛选、添加日程、无横向溢出、云同步兼容和回退验证才能合并上线。
