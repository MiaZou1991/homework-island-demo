# 作业岛儿童端高清视觉资产开发与验收清单（V1）
 
> 依据：用户确认的《作业岛：萌趣学习小岛界面》视觉总览与《四岛家园布置界面》、ChatGPT 资料库 `/作业岛/UI素材库`；本文件是开发标准，不代表素材已完成替换。日期：2026-10-24。
 
## 核心原则
 
1. **保持选定视觉稿**：统一三维绘本玩具风、蓝天海面、奶油色卡片、木纹标牌、绿叶花朵与浣熊伙伴；高清不等于擅自变更风格。
2. **禁止整页截图冒充正式前端**：交互区、文字、状态、导航、弹窗必须为独立 DOM/CSS/SVG 组件，具备可访问文本和真实状态；照片或绘画纹理可作为背景，不要把含文字的 AI 生成稿直接当可交互页面。
3. **场景独立资产**：总览、花园、码头、森林书屋、我的小屋分别提供独立导出的清晰素材；禁止从包含其他页面的拼图裁切作正式场景。
4. **像素密度**：所有 PNG/WebP 至少满足实际渲染宽高 ×2；高频按钮/图标优先 ×3；大幅场景优先 2048px 级或按实际显示尺寸 ×2 以上，不能通过 CSS 放大低分辨率图补救。
5. **组件原生化**：木牌、气泡、卡片、进度条、按钮、底部 Tab、日期与文案以 CSS/SVG/真实字形构建；复杂插画保留高清透明素材，尽量不把 UI 文字烘焙在插画中。
6. **完整性**：所有素材必须边缘平滑且无缺角，无明显白边、棋盘格底、拉伸、模糊、幽灵文字、重复 AI 瑕疵或不一致投影。
7. **性能**：最终交付 WebP/AVIF/PNG 合理组合，保留可追溯无损母版；首屏资源按需加载，不能用巨大的整页 PNG 阻塞交互。不要仅以文件字节数判断清晰度。

## 执行顺序
 
**P0** 首屏视觉：今日任务地图、Logo、三 Tab、今日作业卡、课程小书包、心情与伙伴；目标先解决用户一眼看到的模糊问题。  
**P1** 小岛日程：周/月历、任务详情、编辑弹层与学科物件。  
**P2** 四大布置场景：独立场景图、分类素材栏、可移动透明摆件、撤销与保存。  
**P3** 收藏图鉴、成就奖励、限定活动视觉与空/锁定状态。
 
## 替换记录要求
 
每个资源记录：设计稿编号/模块、现有路径、来源母版、原图实际 px、CSS 显示 px、DPR2/3 是否足够、是否透明/无缺角、同风格比对、压缩后大小、替换 commit、移动设备 QA 结果。**没有测量与对照的资源标为“待验收”，不能标“已高清化”。**
 
## 移动端 QA 验收
 
- 在 375/390/430 CSS px 手机宽度，DPR 2/3 下截图对照获选设计稿；校对主结构、视线焦点、木牌体量、阴影、材质。
- 200% 缩放检查文字、线条、图标、透明边缘和场景局部；无明显模糊或锯齿。
- 场景拖拽、布置前景覆盖、物品缩放及保存后回显均清晰。
- 校对所有中文文字，避免 AI 嵌入错字；按钮与热区具备足够触摸尺寸。
- 验收不得仅凭“用了更大的文件”或“和生成稿一模一样”判定通过。
 
## 发布限制
 
开发只在 `feat/child-ui-hd-assets` 分支进行；未经对比验收不得合并 `main`。原有家长端逻辑、家庭数据、积分和任务规则不可因纯视觉资产替换而被误改。涉及规则与原需求文档不一致之处应单独核对，不与素材更新混在同一提交中。
