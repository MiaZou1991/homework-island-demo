# 作业岛 · 小岛成长整合 Demo

保留原版作业、周期任务、课程、日程、积分、伙伴、家庭奖励和报告功能，整合新的儿童端海岛体验。发布内容位于 `dist/`，无需安装依赖或构建。

## 可以体验什么

- 儿童端：今天、计划、我的小岛；同一时间突出下一件作业。
- 完成作业获得积分、建设力和随机小物件；花园、码头、森林书屋依次建设，四个阶段使用完整海岛场景。
- 积分解锁陪伴伙伴，保留原版十种伙伴及自定义奖励；四位伙伴有插画形象。
- 小物件可摆到房间的书桌、展示架和窗边；支持移动、更换、撤下。
- 家长端：发布与编辑作业、周期作业、文本拆分录入、课程和日程、可选完成确认、奖励兑现、报告与本机备份导入导出。
- 撤销后再次完成沿用同一份掉落与建设记录，防止反复刷取。

## 数据范围

这是用于评审的公开 Demo，不是正式家庭服务。预置的内容均为演示数据。家长端与儿童端在同一浏览器、同一站点下共享本机记录；不同设备不会同步。

使用独立存储键 `homework_island_integrated_demo_v2`，不读取或修改原应用记录，不包含线上家庭连接代码、密钥或数据库。原版云端 AI 和同步已关闭；图片识别保留本机 OCR 回退，需要加载外部 OCR 库，实际图片识别效果尚未完成验收。文字拆分录入已验证。

正式替代旧版前仍需接入家庭身份与权限、云端同步、数据迁移和多设备验收。GitHub Pages 负责静态页面发布，不能替代这些后端能力。

## 本地预览

在本目录运行：

```sh
python3 -m http.server 8178 --bind 127.0.0.1 --directory dist
```

打开 `http://127.0.0.1:8178/`。通过入口选择儿童端或家长端。

## GitHub Pages 发布

1. 将本目录内容上传至 `homework-island-demo` 仓库的 `main` 分支，保留隐藏目录 `.github/`。
2. 在仓库 Settings → Pages → Build and deployment 中，Source 选择 GitHub Actions。
3. 在 Actions 运行 Publish Homework Island Demo；之后每次推送 main 都会自动检查并发布 `dist/`。
4. 成功后在 Pages 或部署记录中取得实际访问地址。

本仓库未预设用户名、域名或 CNAME。可先使用 GitHub 分配的网址；购买域名后在 Pages 的 Custom domain 配置，并按 GitHub 文档添加 DNS 记录。


14 项领域与隔离检查覆盖积分、撤销、固定掉落、课程打卡、周期任务、旧备份兼容和生产数据隔离。结果位于 `checks/domain-results.json`。

浏览器已操作验证：完成作业、花园建设、父子端切换、文本批量发布、报告、房间摆放；检查移动端布局和图片加载。截图位于 `checks/`。尚未验证 GitHub 实际部署、图片 OCR、正式云端同步。
