# 开心岛｜家庭树 V3 已确认视觉稿落地说明

## 设计来源和目标

- 已确认的素材基准：`开心岛家庭树成长记录.png`、`开心岛家庭树入口.png`、`开心岛家庭树弹窗系统图谱.png`（2026-11-10）。
- **不是将设计图整体铺成底图**：页面中的中文文字、按钮、记录、头像、回复、数据与弹窗仍以真实 DOM 展示与交互，插画只承担场景氛围，木牌/花枝/按钮采用可伸缩 SVG。
- 延续浅木牌、奶油纸张、树枝吊牌、绿色高对比按钮、粉白花枝和轻微降低的饱和度，避免上一版普通表单感。
- 仅修改视觉与展示位置，不接触身份、云端记录、增减积分或家庭存储。

## 页面验收范围

- 上部：树景/木牌/三条树枝吊牌/家庭树成长板的文字仍是交互内容；中间必须能看见树干与花坛，吊牌及成长板不可互相遮挡。
- 中部：「家庭记录｜送爱心」两个 Tab，可切换；家庭记录含成长回忆、家庭便签两种分类；写记录的绿色按钮清晰可点。
- 弹窗：已沿用 V2.1 的逻辑并统一更换木牌标题、花枝角饰、奶油纸边框和可读的确认/取消按钮，包括新增、详情回复、送心、已达限额、成功、成长历程、删除和异常。
- 小岛入口：家庭树近景必须显示树根/花坛融合图，不允许独立叠树和人物 PNG。
- 宽度：320、375、390、430px；检查无横向溢出、操作区不叠压，WebP 最小分辨率校验，弹窗可用。
- 原有业务检查：家庭记录增删改、回复、私密爱心预览、每人每天两颗、五年成长时间门槛继续保持通过。

3. 当前每人每天最多 2 颗心和五年成长依赖 PR #25 的本机体验逻辑，后续服务端成员身份、跨设备事务限额、私密心意 RLS、图片私有存储仍然是生产上线阻断项。
