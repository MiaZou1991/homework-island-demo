# 儿童端弹窗统一样式 · 2026-10-28

共用素材：`dialog-panel-v1.svg` 手绘面板、`dialog-title-v1.png` 木牌。标题使用 DOM 文字，居中于木牌；关闭按钮相对面板上边、右边各 25 CSS px。正文可滚动，标题与关闭按钮保留可见。按钮改为轻微不规则圆角长条。

统一入口覆盖：
- 今日任务：全部任务、作业详情、完成记录、记心情、陪伴伙伴与伙伴图鉴、课程详情。
- 日程：日程详情、添加及编辑日程、删除日程确认。
- 小岛：建设完成、兑换确认。
- 旧版入口：伙伴选择、个人资料编辑、动态编辑器及通用确认。
- 非预览模式：家庭码及家长验证面板（只统一外观，保留原有验证过程）。

原生儿童端删除日程确认已接入通用确认面板；家长端保持原流程。

人工预览核对：全部任务、心情、伙伴、课程、作业详情、完成记录、添加日程和兑换确认。全部任务关闭按钮实测上/右均为 25px。添加日程滚动区和关闭动作正常；兑换确认检查后取消，未兑换。

首页同时修正：快捷按钮减小弧度，作业完成勾缩小，导航为标签预留底部空间，全部任务使用独立学科图片。
