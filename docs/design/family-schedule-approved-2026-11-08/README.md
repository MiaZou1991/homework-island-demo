## 已确认范围

- 今日日程：一周日期栏、全家／开心／爸爸／妈妈筛选、当天时间线、记一件事入口、出门携带提醒。
- 一句话添加：一个主输入框，自动整理可识别的时间和人物，显示摘要供检查，直接保存；未识别内容保留为文字，无时间时放“时间未定”。
- 当前选中日期和成员作为默认值；更多设置折叠；最近安排一键复用。
