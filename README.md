# 作业岛 · 小岛日历

在线体验：https://miazou1991.github.io/homework-island-demo/

当前更新：20261019f · 儿童端日常流程、事项弹窗与房间角色尺寸优化。

在今天的作业卡和作业详情中，可以直接选择和更换陪写伙伴；同一伙伴会贯穿作业、小岛、房间与完成时刻。场景角色使用更清晰的立绘、脚下接触阴影和独立站位。

保留原版作业、周期任务、课程、日程、积分、伙伴、家庭奖励和报告功能，整合新的儿童端海岛体验。发布内容位于 `dist/`，无需安装依赖或构建。

## 可以体验什么

- 儿童端：今天、计划、我的小岛；同一时间突出下一件作业。
- 完成作业获得积分、建设力和随机小物件；花园、码头、森林书屋依次建设，四个阶段使用完整海岛场景。
- 积分解锁陪伴伙伴，保留原版十种伙伴及自定义奖励；十位伙伴都有完整插画形象。
- 小物件可摆到三层展示架的 12 个位置，以及书桌 2 处、窗边 1 处；支持按拥有数量摆多件、移动、交换、替换和收回，保留旧版三个位置的摆件。
- 家长端：发布与编辑作业、周期作业、课程和日程、可选完成确认、奖励兑现与报告。
- 撤销后再次完成沿用同一份掉落与建设记录，防止反复刷取。
- 今日作业未全部完成时，完成弹窗主按钮为“继续下一个”，直接打开下一份作业。完成今日作业并通过需要的家长确认后，才开放建设小岛和布置房间；课程、自由日程和明日作业不阻塞。
- 儿童端“今天”页提供心情与小记录入口：可只选心情、只写文字或两者一起，按日期保存、编辑和回看；旧版心情签名保留，记录不发放积分。
- 日程准备清单按钮明确显示“＋ 添加准备物品”。

## 数据范围

该站点目前仍是静态网页版本。家长端与儿童端在同一浏览器中共享本机记录；不同设备不会同步，正式家庭使用前仍需接入云端数据库和成员权限。

使用独立存储键 `homework_island_integrated_demo_v2`，不读取或修改原应用记录，不包含线上家庭连接代码、密钥或数据库。原版云端 AI 和同步已关闭；图片识别保留本机 OCR 回退，需要加载外部 OCR 库，实际图片识别效果尚未完成验收。文字拆分录入已验证。

正式替代旧版前仍需接入家庭身份与权限、云端同步、数据迁移和多设备验收。GitHub Pages 负责静态页面发布，不能替代这些后端能力。

## GitHub Pages 发布

1. 将本目录内容上传至 `homework-island-demo` 仓库的 `main` 分支，保留隐藏目录 `.github/`。
2. 在仓库 Settings → Pages → Build and deployment 中，Source 选择 GitHub Actions。
3. 在 Actions 运行 Publish Homework Island；之后每次推送 main 都会自动检查并发布 `dist/`。
4. 成功后在 Pages 或部署记录中取得实际访问地址。

本仓库未预设用户名、域名或 CNAME。可先使用 GitHub 分配的网址；购买域名后在 Pages 的 Custom domain 配置，并按 GitHub 文档添加 DNS 记录。
