# 家庭日历本地实施 · 2026-11-08

## 本轮已实现

- 保留最终 Logo 原资源和原底部 Tab 图标、标签、样式与入口；只替换日历内容与轻量编辑器。
- 全家／开心／爸爸／妈妈筛选、日期条与日/月切换、真实数据时间线、去重携带提醒。
- 已有固定课程按原课表出现。原课程与家长日程编辑保护不变；成员标签只影响展示，不授予编辑权。
- 一句话添加：支持中文数字时间、半点、一刻、三刻、上午/下午/晚上和 24 小时时间；识别人物，展示摘要；不能识别时保留文字，无时间也能保存。
- 更多设置可改选中日期、时间、成员和携带物品；最近已有日程可复用内容、时间和携带物品。
- 新增、编辑、删除接原保存机制；历史事件缺少成员时按孩子日程展示，不迁移或删除历史数据。
- 页面采用真实 DOM 文字和按钮；海岛背景等比覆盖，纸面九宫格边缘不拉伸。

## 当前边界

- 未发布，未改云端权限。家庭三身份设备授权仍属既有后续阶段；成员筛选不能当作身份验证或隐私权限。
- 中文识别为本地规则，尚非通用自然语言理解；“明天／下周”等日期词不会自动改日期，请使用更多设置。固定课表沿用原机制，本轮不新增自由日程重复规则或单次例外编辑流程。
- 视觉对照还原，背景和纸面为参考稿重建素材；不是原稿逐像素切图，不能宣称100%逐像素一致。Logo/Tab 按用户要求保留，故有意与示意稿不同。
