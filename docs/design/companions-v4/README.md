## 小兔透明底修复（2026-11-09）

用户实机截图发现今日任务中的小兔周围出现大块奶油色雾状矩形。根因为旧 `companion-rabbit-v4.png` 仅柔化了裁图边缘，卡片背景仍保留了接近不透明的像素，并非真正抠图。现新增 `companion-rabbit-v5.png` 真正透明的独立立绘，`companions-v4.json` 和 `DemoCore.companions` 中兔子的资源路径已更新，保留旧图以便回退；PNG 原造型、耳朵/表情/背包比例不变。

防回归：页面加载后由手机自动化通过 canvas 检查双耳之间透明度，以及小兔面部的不透明度，并检查 JS 缓存版本。余下 15 位 v4 角色裁图具有类似奶油底纹残留风险，需在单独素材审查中逐项处理，不能将其标记为已全部抠净。
