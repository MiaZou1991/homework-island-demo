# 成长日历｜视觉精准还原验收说明 V1.1
日期：2026-11-10。参考：用户在当前项目提供的“月历 + 日期弹窗 + 右侧需求说明”合成设计图。状态：PR #29 的视觉还原稿，尚未验收/合并。

## 还原范围（左手机+中间日期弹层）
右侧“功能需求梳理”是设计注释面板，不是产品真实页面，不应部署进入应用。

### 页面主体
- 同一个「成长日历」Tab 内切换「周视图 / 月视图」，底部继续沿用现有导航 DOM、图标与选中态；保留最终 Logo。
- 顶部：晴空 + 灯塔 + 绿叶小花点缀，木质主标题；周/月视图为小巧的奶油/绿色切换钮，月份单独圆角胶囊。
- 内容底色：暖奶油白，压低大面积蓝色海水与花草饱和度。保留轻小岛感，内容区不再铺满照片背景。
- 全局：真实 DOM 字体，圆角、描边和阴影与高分辨率插画分层，绝不把设计稿作为一张背景直接铺到网页上。

### 月历模块
- 7 列日期、浅金分隔线、纸纹奶油底、周末红日期、选中日叶绿渐变与奶油白描边。
- 一天最多两个成长标记，剩余展示小号 +N；标记优先级：心情、任务完成、习惯打卡、特别时刻。
- 四类贴纸采用单独图像（assets/hd/growth-calendar/heart/star/leaf/flower.svg）。心情仍使用原 mood SVG，不虚构“开心”。
- 月视图不显示成员筛选；周视图保留成员筛选和现有“一句话记事”入口。

### 本月手账
- 木质小标题 + 角落花叶、活页边孔/金色装订、斜放照片卡、手写感的短句、角落铅笔。
- 月度内容来自现有心情短句，不使用设计示例中的虚构达成次数。
- 记事插画使用新独立矢量素材 memory-autumn.svg，不拉伸整张手账卡片。

### 21天挑战
- 纸张式独立卡片、木牌标题、真实挑战名称、累计 X/21 天、绿色进度条、21 格小印章。
- 无挑战时呈现添加入口，不能冒充已打卡 12 天。
- 只记录习惯，不增加积分；漏一天不清零。

### 日期详情弹窗
- 复用原弹窗底层结构：半透明遮罩、奶油纸面、独立关闭圆钮。
- 当前陪伴伙伴探头置于标题条后，伙伴来源和「今日任务」一致。
- 顶部显示选中日期 + 三枚彩色摘要：实际心情、当天任务完成、习惯数量。
- 下方：我的小记录纸条（短句可编辑）；当天安排按作业/课程/携带物品分组；习惯逐项打卡；特别时刻可添加。
- 课程和携带物品仅提示，不显示完成勾选；当天没作业不显示任务完成星星。

## 尺寸与排版验收
设计以 390px 手机宽度作为主基准，再核对 320、375、430px：
- 顶部木牌建议约 174x65 CSS px；月切换按钮不与标题争抢宽度。
- 月历日期格约 59px 高（320px 下缩至 51px）；图标约 21px（窄屏更小）；+N 在格内浮于角落，不能溢出邻格。
- 月历下方有独立图例；手账与挑战卡片之间留出透气间距，卡片上方木牌不能遮挡内容。
- 日期详情在移动端可滚动，标题、关闭钮和伙伴不重叠；任何交互不能被底栏遮挡。
- 视觉验收采用三个实际浏览器截图：月视图、日期弹层、周视图；同屏对照参考设计，逐项检查结构、尺寸、字重、图标、阴影和素材清晰度。

## 实施文件
- `dist/growth-calendar.js`：真实周/月日历、手账、进度、弹窗内容
- `dist/growth-calendar.css`：纸张、木牌、日期网格、装订、阴影、弹窗组件
- `dist/assets/hd/growth-calendar/`：独立贴纸与秋日插画
- `dist/upgrade.js`：保留既有导航/心情数据，注入当前伙伴
- `checks/growth-calendar-mobile.cjs`：四种屏宽，截图输出至 GitHub Actions 构建工件

## 限制
该稿是用 HTML/CSS/矢量素材尽量贴近单张合成参考图的实现，并非已取得原始字体/分层插画的逐像素切图；只有将实际浏览器截图与参考图在同尺寸逐项对照，并人工验收后，才可称“视觉还原通过”。目前 PR 为 Draft，不得自行合并上线。
